# Functional Requirements

## Core TODO App Requirements

1. The user can create a new task with a title.
2. The user can optionally add a description to a task.
3. The user can set an optional due date for a task.
4. The user can edit an existing task (title, description, due date).
5. The user can mark a task as complete.
6. The user can mark a completed task as incomplete.
7. The user can delete a task.
8. The user can view all tasks in a task list.
9. The user can filter tasks by status (all, active, completed).
10. The user can sort tasks in a consistent order:
    - By due date (earliest first)
    - Then by creation time (newest first)
11. Overdue tasks are visually distinguishable from non-overdue tasks.
12. Completed tasks remain visible in the list until deleted.
13. Task data persists after page refresh (stored locally).
14. The app validates task input and prevents creating tasks with an empty title.
